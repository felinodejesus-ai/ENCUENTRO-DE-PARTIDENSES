ENCUENTRO DE PARTIDENSES 2026

- index.html
- imagenes/escudo-partido.png
- imagenes/logo-partido.png
- imagenes/afiche-encuentro.png
- imagenes/paisaje-partido.jpg
- imagenes/referencia-diseno.png

Para publicar:
1. Sube index.html y la carpeta imagenes a tu repositorio de GitHub.
2. Mantén exactamente los nombres de los archivos.
3. Si cambias el lugar exacto del evento, modifica el texto y el enlace de Google Maps en index.html.
4. La fecha del contador está configurada para el 29 de agosto de 2026 a las 00:00, zona horaria UTC-4 (República Dominicana).

La imagen paisaje-partido.jpg es un fondo panorámico derivado del afiche suministrado para que la página funcione de inmediato sin recursos externos.
